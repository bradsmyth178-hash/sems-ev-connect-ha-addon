# Changelog

## 0.6.1

- Pairing is now an eight-character code instead of a long block of text. It is
  single-use and expires after seven days.
- The control PIN is optional: leave it blank and one is generated and shown once.
- The charger's serial is found from your GoodWe account, so there is nothing to
  read off the unit.
- Settings that could not change the outcome moved behind **Advanced settings**.
- Clearer errors when a sign-in fails, so it is obvious whether the problem is
  the account or the charger.
